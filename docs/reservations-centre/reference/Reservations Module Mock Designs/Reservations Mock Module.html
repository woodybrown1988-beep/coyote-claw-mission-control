Recommended data architecture

Source-of-truth separation prevents false customer and revenue conclusions

OpenTable GuestCenter

Reservations, source, status, party size, visit history, notes, tags, cancellations, no-shows, waitlist, reviews and guest profiles.

PRIMARY RESERVATION SOURCE

Lightspeed K-Series

Checks, covers, revenue, spend per cover/party, order details and table-status signals when the POS integration is active.

DINE-IN VALUE LAYER

LivePepper / COMO

Takeaway orders, loyalty identity, order frequency, channel behaviour, offers and last takeaway interaction.

TAKEAWAY CUSTOMER LAYER

Customer identity map

Normalize consented phone/email, keep source IDs, preserve opt-ins, avoid duplicate profiles and maintain role-based access.
